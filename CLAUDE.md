# CLAUDE.md - AI Assistant Guide for DeskApp

## Project Overview

DeskApp is a free Bootstrap 4 admin dashboard template (v3.0.0) designed for creating admin panels and back-end dashboards. It's a front-end only, static HTML template project with no backend.

- **Author:** Ankit Hingarajiya
- **License:** MIT
- **Repository:** https://github.com/dropways/deskapp

## Development Workflow

### Prerequisites

```bash
npm install          # Install dependencies
```

### Build Commands

```bash
gulp                 # Default task: build all + start BrowserSync with live reload
gulp styles          # Compile src/styles/*.css → vendors/styles/style.css
gulp corestyle       # Compile plugin CSS → vendors/styles/core.css
gulp icon_styles     # Compile icon fonts → vendors/styles/icon-font.css
gulp scripts         # Compile src/scripts/*.js → vendors/scripts/script.js
gulp core            # Compile core libraries → vendors/scripts/core.js
gulp fonts           # Copy fonts to vendors/fonts/
gulp images          # Optimize images to vendors/images/
```

### Local Development

1. Run `gulp` to start the development server
2. BrowserSync serves at `localhost:3000` (proxies `localhost/deskapp`)
3. Changes to files in `src/` trigger automatic rebuild and reload

### Build Pipeline

- **CSS:** Source files → Sass → CSSO → Autoprefixer → Concatenate → Minify (.min.css)
- **JS:** Source files → Concatenate → Uglify (.min.js)
- **Images:** Imagemin optimization

## Code Conventions

### JavaScript (src/scripts/setting.js)

- jQuery-based DOM manipulation
- Uses `jQuery(document).ready()` for initialization
- Plugin initialization on page load
- Custom jQuery plugins (e.g., `vmenuModule` for sidebar accordion)
- Event delegation with data attributes (`data-toggle`, `data-color`, etc.)
- HTML escaping for security (XSS prevention)

```javascript
// Example pattern - plugin initialization
jQuery(document).ready(function() {
    "use strict";
    $(".custom-select2").select2();
    $('[data-toggle="tooltip"]').tooltip();
});
```

### CSS (src/styles/)

- Mobile-first responsive design
- Load order: `theme.css` → `style.css` → `media.css`
- BEM-like class naming conventions
- Minified versions created automatically (`.min.css`)

### HTML Pages

- All 64 pages inherit the same template structure
- Include Google Analytics and AdSense integration
- Use Inter font from Google Fonts
- Consistent CSS/JS references to vendors/ directory

## Common Tasks for AI Assistants

### Adding a New Page

1. Copy an existing HTML page as template
2. Modify content between `<main>` tags
3. Update sidebar menu in the HTML if needed
4. Ensure CSS/JS references point to `vendors/` directory

### Modifying Styles

1. Edit files in `src/styles/`
2. Run `gulp styles` to compile
3. Both `.css` and `.min.css` are generated in `vendors/styles/`

### Adding Custom JavaScript

1. Edit `src/scripts/setting.js`
2. Run `gulp scripts` to compile
3. Output goes to `vendors/scripts/script.js`

### Adding a New Plugin

1. Add plugin files to `src/plugins/[plugin-name]/`
2. Update `gulpfile.js` paths if CSS/JS needs to be bundled
3. Run appropriate gulp task (`gulp core` or `gulp corestyle`)
4. Include plugin initialization in `setting.js`

## Notes for AI Assistants

1. **Never edit files in `vendors/`** - they are auto-generated from `src/`
2. **Run Gulp after editing source files** to see changes reflected
3. **BrowserSync proxy** expects a local server at `localhost/deskapp` - modify in `gulpfile.js` if different
4. **This is front-end only** - no backend/API code exists
5. **jQuery patterns** - use jQuery for DOM manipulation, not vanilla JS
6. **Plugin conflicts** - be aware of multiple versions of similar libraries
7. **IE support** - code includes IE detection and compatibility handling
