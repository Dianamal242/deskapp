# CLAUDE.md

## Project Overview

DeskApp is a free Bootstrap 4 admin dashboard template (v3.0.0). It is a static HTML/CSS/JS project — there is no backend, no framework, and no component system. All pages are standalone `.html` files in the project root.

**Repository:** `dropways/deskapp`
**License:** MIT

## Tech Stack

- **CSS Framework:** Bootstrap 4
- **JavaScript:** jQuery (vanilla JS with jQuery plugins)
- **Build Tool:** Gulp 4 (task runner for concatenation, minification, autoprefixing)
- **CSS Preprocessing:** Node-sass via gulp-sass
- **Package Manager:** npm
- **Live Reload:** BrowserSync

## Build System (Gulp)

### Key Gulp Tasks

| Task | Description |
|------|-------------|
| `styles` | Compiles `src/styles/{theme,style,media}.css` → `vendors/styles/style.css` + `.min` |
| `corestyle` | Bundles plugin CSS → `vendors/styles/core.css` + `.min` |
| `icon_styles` | Bundles icon font CSS → `vendors/styles/icon-font.css` + `.min` |
| `scripts` | Bundles `src/scripts/setting.js` → `vendors/scripts/script.js` + `.min` |
| `core` | Bundles jQuery + plugin JS → `vendors/scripts/core.js` + `.min` |
| `fonts` | Copies font files from `src/fonts/` → `vendors/fonts/` |
| `images` | Optimizes images from `src/images/` → `vendors/images/` |
| `default` | Runs all tasks + watches for changes + BrowserSync |

### Running the Build

```bash
npm install
npx gulp              # Full build + watch + live reload
npx gulp styles       # Rebuild custom styles only
npx gulp scripts      # Rebuild custom scripts only
```

BrowserSync is configured to proxy `localhost/deskapp` on port 3000.

## Important Conventions

### File Organization
- **Edit source files in `src/`**, never edit `vendors/` directly — those are build outputs
- All HTML pages are flat in the root directory (no subdirectories for pages)
- Each HTML page is self-contained with its own inline scripts and plugin includes

### HTML Page Structure
Every page follows this pattern:
1. `<head>`: Core CSS (`vendors/styles/core.css`), icon fonts, theme styles, page-specific plugin CSS
2. `<body>`: Header, left sidebar, main content, right sidebar, footer
3. Bottom scripts: `vendors/scripts/core.js`, `vendors/scripts/script.js`, page-specific plugin JS, inline `<script>` blocks

### CSS Architecture
- `src/styles/theme.css` — Color scheme, branding variables
- `src/styles/style.css` — Main layout and component styles
- `src/styles/media.css` — Responsive breakpoints / media queries

### JavaScript
- jQuery is the primary JS library (`src/scripts/jquery.min.js`)
- `src/scripts/setting.js` — Sidebar toggle, scrollbar init, SVG conversion, layout utilities
- Page-specific JS is written inline in each HTML file
- Uses `"use strict"` mode

### Plugins (in `src/plugins/`)
Major plugins include: ApexCharts, Highcharts, DataTables, FullCalendar, Select2, Dropzone, SweetAlert2, Slick Slider, CropperJS, jQuery Steps (form wizard), jQuery Knob, Ion RangeSlider, Plyr (video), jVectorMap.

## CI/CD

GitHub Actions workflow (`.github/workflows/npm-publish.yml`):
- Triggers on release creation
- Runs `npm ci` and `npm test` (note: test script is a no-op placeholder)
- Publishes to npm and GitHub Package Registry

## Development Notes

- No test suite exists — `npm test` just echoes an error message
- No linter or formatter is configured
- Node.js 12 is specified in CI (legacy)
- The project uses `node-sass` (deprecated) — may need `npm install` with `--legacy-peer-deps` or Python 2 build tools on newer systems
- `.gitignore` excludes: `node_modules/`, `bower_components/`, `.sass-cache/`
- The `vendors/` directory IS committed to the repo (not gitignored)
