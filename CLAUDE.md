# CLAUDE.md - AI Assistant Guide for DeskApp

## Project Overview

DeskApp is a free, open-source **Bootstrap 4 admin dashboard HTML template** (v3.0.0). It provides 64 pre-built static HTML pages for admin panels and back-end dashboards. There is no backend — this is a pure frontend template project.

**Repository:** `github.com/dropways/deskapp`
**License:** MIT
**Author:** Ankit Hingarajiya

## Tech Stack

- **CSS Framework:** Bootstrap 4
- **JavaScript:** jQuery 3.5.1
- **Build System:** Gulp 4.0.2
- **CSS Preprocessing:** SASS (via `node-sass`)
- **Fonts:** Google Fonts (Inter, weights 300-800)
- **Icons:** 6 icon sets — Bootstrap Icons, Font Awesome, Ionicons, Themify, Foundation, Dropways custom

## Directory Structure

## Build System

### Gulp Tasks

| Task | What it does |
|------|-------------|
| `styles` | Compiles `src/styles/{theme,style,media}.css` → `vendors/styles/style.css` + `.min.css` |
| `corestyle` | Bundles plugin CSS → `vendors/styles/core.css` + `.min.css` |
| `icon_styles` | Bundles icon font CSS → `vendors/styles/icon-font.css` + `.min.css` |
| `scripts` | Compiles `src/scripts/setting.js` → `vendors/scripts/script.js` + `.min.js` |
| `core` | Bundles jQuery + plugins → `vendors/scripts/core.js` + `.min.js` |
| `fonts` | Copies font files to `vendors/fonts/` |
| `images` | Optimizes images to `vendors/images/` |
| `default` | Runs all tasks + BrowserSync live-reload on `localhost/deskapp` |

### Running the Build

```bash
npm install          # Install dependencies
npx gulp             # Run default task (build all + watch + live-reload)
npx gulp styles      # Build only custom styles
npx gulp scripts     # Build only custom scripts
```

BrowserSync proxies `localhost/deskapp` — update this in `gulpfile.js` line 231 if your local server path differs.

### Build Pipeline (per asset type)

- **CSS:** Source → SASS compile → CSSO optimize → Autoprefixer → Concatenate → Clean-CSS minify
- **JS:** Source → Concatenate → Uglify minify
- **Images:** Source → imagemin optimize (only changed files)
- **Fonts:** Source → direct copy

## Key Development Rules

### Source vs. Build Output

- **EDIT** files in `src/` — these are the source of truth
- **NEVER** directly edit files in `vendors/` — they are generated by Gulp
- After editing `src/` files, run the appropriate Gulp task to rebuild `vendors/`
- Page-specific scripts in `vendors/scripts/` (e.g., `dashboard.js`, `datatable-setting.js`) are NOT built by Gulp — they are standalone vendor files

### HTML Page Structure

Every HTML page follows this consistent structure:

```html
<!DOCTYPE html>
<html>
<head>
  <!-- Meta tags, favicon, Google Fonts (Inter) -->
  <link rel="stylesheet" href="vendors/styles/core.css">
  <link rel="stylesheet" href="vendors/styles/icon-font.min.css">
  <link rel="stylesheet" href="vendors/styles/style.css">
  <!-- Google Analytics + AdSense (optional) -->
</head>
<body>
  <div class="pre-loader">...</div>           <!-- Loading spinner -->
  <div class="header">...</div>                <!-- Top navigation bar -->
  <div class="left-side-bar">...</div>         <!-- Sidebar navigation -->
  <div class="main-container">                 <!-- Page content -->
    <div class="pd-ltr-20">...</div>
  </div>
  <script src="vendors/scripts/core.js"></script>
  <!-- Page-specific plugin scripts -->
  <script src="vendors/scripts/script.min.js"></script>
</body>
</html>
```

### CSS Conventions

- **Bootstrap 4 grid:** `.container`, `.row`, `.col-{breakpoint}-{size}`
- **Custom utility classes:** `.mb-20`, `.pd-20`, `.font-24` (spacing/sizing)
- **Card containers:** `.card-box` with `.card-header` + `.card-body`
- **Class naming:** Hyphen-separated, BEM-like (e.g., `.header-search`, `.custom-scroll`)
- **Responsive breakpoints:** sm (576px), md (768px), lg (992px), xl (1200px)

### JavaScript Conventions

- All custom JS uses jQuery with strict mode inside `$(document).ready()`
- Configuration via HTML5 `data-*` attributes: `data-toggle`, `data-color`, `data-bgcolor`, `data-border`
- Plugin initialization happens on document ready
- Event delegation pattern with `.on('click', ...)` handlers

### File Naming

- **HTML pages:** `kebab-case.html` (e.g., `form-basic.html`, `ui-buttons.html`, `blog-detail.html`)
- **JS files:** `kebab-case.js` with `-setting.js` suffix for plugin configs
- **CSS files:** `kebab-case.css`
- **Both regular and `.min` versions** are generated for CSS and JS

## Common Tasks for AI Assistants

### Adding a new page
1. Copy `blank.html` as a starting template
2. Update the `<title>` and breadcrumb navigation
3. Add sidebar navigation link in the `<div class="left-side-bar">` section
4. Include any page-specific plugin CSS/JS before the closing tags
5. Always load `core.css`, `icon-font.min.css`, `style.css` (CSS) and `core.js`, `script.min.js` (JS)

### Modifying styles
1. Edit files in `src/styles/` (primarily `style.css` for component styles, `media.css` for responsive rules, `theme.css` for theme variables)
2. Run `npx gulp styles` to rebuild
3. Never edit `vendors/styles/` directly

### Adding a new plugin
1. Place plugin files in `src/plugins/{plugin-name}/`
2. If it should be part of the core bundle, add its CSS to `path.corestyle` and/or JS to `path.core` in `gulpfile.js`
3. Otherwise, reference it directly in individual HTML pages
4. Create a `{plugin-name}-setting.js` in `vendors/scripts/` for initialization code

### Modifying JavaScript behavior
1. Edit `src/scripts/setting.js` for global behavior (sidebar, header, theme settings)
2. Run `npx gulp scripts` to rebuild
3. Page-specific scripts in `vendors/scripts/` (e.g., `dashboard.js`) can be edited directly — they are not part of the Gulp build pipeline
