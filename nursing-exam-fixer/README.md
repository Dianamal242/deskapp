# 🏥 מערכת תיקון שאלות בחינה סיעודית

מערכת לתיקון ושיפור שאלות בחינה סיעודית בעברית.

## 📋 תכונות

- ✅ תיקון ניסוח שאלות לא ברורות
- ✅ תיקון ותרגום תשובות (עברית + אנגלית)
- ✅ הוספת מסיחים חסרים (עד 4 לכל שאלה)
- ✅ שיפור לשוני - דקדוק, תחביר, פיסוק
- ✅ ציון איכות לכל שאלה (0-100)
- ✅ מיון לפי חטיבות
- ✅ עיצוב Excel מקצועי עם צבעים

## 🚀 התקנה על Mac

### שלב 1: וודאי ש-Python מותקן
```bash
python3 --version
```

אם לא מותקן, התקיני מ: https://www.python.org/downloads/

### שלב 2: הורידי את הקבצים

שמרי את כל הקבצים מתיקיית `nursing-exam-fixer` לתיקייה על המחשב שלך.

### שלב 3: התקני את הספריות הנדרשות
```bash
cd /path/to/nursing-exam-fixer
pip3 install -r requirements.txt
```

## 📖 הפעלה

### אפשרות 1: הפעלה אינטראקטיבית
```bash
python3 nursing_exam_processor.py
```

המערכת תבקש ממך:
1. נתיב לקובץ Excel
2. מה תרצי לעשות (תפריט)

### אפשרות 2: שימוש כמודול Python
```python
from nursing_exam_processor import NursingExamProcessor

# יצירת מעבד
processor = NursingExamProcessor('/path/to/your/file.xlsx')

# טעינת הקובץ
processor.load_file()

# עיבוד כל הגיליונות
for sheet_name in processor.df_dict.keys():
    processor.process_sheet(sheet_name)

# שמירה
processor.save()

# הצגת דוח
print(processor.generate_report())
```

## 🔤 כללי תיקון

### פיסוק
- ✅ הוספת סימן שאלה אם חסר
- ✅ הסרת רווחים כפולים
- ✅ תיקון `:?` ל-`?`
- ✅ הסרת רווח לפני סימן פיסוק

### תשובות
- ✅ תרופות: אנגלית + עברית בסוגריים - `Morphine (מורפין)`

- ✅ תמיסות: אנגלית בלבד - `Normal Saline 0.9%`
